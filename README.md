# just_in_time_01_2026

Sistema Web Full Stack desenvolvido para uma empresa fabricante de MDF, com o objetivo de auxiliar no gerenciamento de produtos, estoque, produção e pedidos, seguindo o conceito de **Just in Time**.

O sistema permite controlar a quantidade de produtos em estoque, registrar produtos, realizar movimentações de produção e pedidos e emitir alertas quando o estoque atinge ou fica abaixo do estoque mínimo.

---

## Sobre o projeto

O projeto foi desenvolvido como parte da atividade de desenvolvimento **Web Full Stack**, tendo como proposta solucionar a necessidade de uma empresa que trabalha com produção de MDF e deseja manter seu estoque reduzido, evitando desperdícios e produzindo de acordo com a demanda.

A aplicação possui:

- Sistema de login;
- Controle de usuários;
- Cadastro de produtos;
- Consulta e pesquisa de produtos;
- Edição e exclusão de produtos;
- Controle de estoque;
- Registro de produção;
- Registro de pedidos;
- Atualização automática do estoque;
- Alerta de estoque mínimo;
- Histórico de movimentações.
